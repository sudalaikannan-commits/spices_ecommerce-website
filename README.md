# SpiceKart Complete Frontend

A complete responsive frontend prototype for the SpiceKart spices e-commerce project.

## Stack
HTML5 + CSS3 + Vanilla JavaScript only.

## Included
- Home page
- Product listing/search
- Product details
- Cart + quantity controls
- Wishlist
- Login/Register UI
- Account
- Orders
- Checkout
- Dummy payment
- Order success
- About/Contact
- Full admin UI: login, dashboard, products, add product, categories, orders, customers, coupons, reviews, settings
- Responsive mobile 310px–767px, tablet, laptop and desktop
- localStorage demo cart/wishlist/coupon
- No PHP/MySQL/Razorpay yet

## Run
Open this folder in VS Code and use Live Server on `index.html`.

## Backend handoff
Your friend can later connect PHP + MySQL + PDO by replacing the demo JavaScript data/state with server endpoints. Do not use the demo frontend authentication as production security.
